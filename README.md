# Capybraita

**Capybraita** is a (WIP) game made for a [Hackclub](https://hackclub.com) hackathon in Bogota, Colombia.

## The Game
In Caoybraita you play as a broke capybara wanting to save up for a computer. You complete mini games around a colombian neighborhood to earn mangoes, the currency. However to stay alive, you must eat mangoes.
