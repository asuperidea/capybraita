# Capybraita

**Capybraita** is a (WIP) game made for a [Hackclub](https://hackclub.com) hackathon in Bogotá, Colombia.

## The Game
In Capybraita, you play as a broke capybara wanting to save up for a computer. You complete minigames around a Colombian neighborhood to earn mangoes, the currency. However, to stay alive, you must eat mangoes.

Follow the starting screens to learn about the "lore" and select your character.

Click on houses to start minigames; follow the instructions on the screen to complete the tasks.

Over time, your hunger will deplete. Click 'E' to eat.
